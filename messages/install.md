LSP-zuban
---------

This plugin provides LSP bindings ("LSP" package must be installed).

Even without LSP, you can use `zuban check` manually (via Command Palette).

IMPORTANT:
- The server is currently disabled globally.

You can either:
- enable it globally (which uses `uv` for updates)
- or set a path to a `zuban` binary in settings (local mode).
